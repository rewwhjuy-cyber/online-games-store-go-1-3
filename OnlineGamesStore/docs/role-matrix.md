# Матрица ролей

| Endpoint / действие | CUSTOMER | MANAGER | ADMIN |
|---|---:|---:|---:|
| Просмотр каталога | Да | Да | Да |
| Регистрация/вход | Да | Да | Да |
| Просмотр/изменение своей корзины | Да | Нет | Нет |
| Создание заказа | Да | Нет | Нет |
| Просмотр собственных заказов | Да | Да | Да |
| Просмотр всех заказов | Нет | Да | Да |
| Получение чужого заказа по ID | 404 | Да | Да |
| Изменение статуса заказа | Нет | Да | Да |
| Создание/изменение игры | Нет | Да | Да |
| Просмотр audit log | Нет | Нет | Да |
| Самостоятельное назначение роли | Нет | Нет | Нет |

401 — нет/неверный/истёкший access JWT. 403 — аутентифицирован, но роль не разрешена. 404 для чужого заказа предотвращает раскрытие существования чужого объекта.
